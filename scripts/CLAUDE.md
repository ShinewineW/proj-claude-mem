# Scripts

Mix of build-generated outputs (`.cjs` via esbuild) and manually-maintained source scripts. Do NOT read `.cjs` hook files here — read source in `src/` instead.

## Source Scripts (manually maintained)

| Script | Purpose | Safe to run manually? |
|--------|---------|----------------------|
| `smart-install.js` | Hook: ensure bun + uv installed, install deps if needed | Yes (idempotent) |
| `bun-runner.js` | Hook: start worker via bun runtime | Yes |
| `build-hooks.js` | Build: compile TS hooks → `plugin/scripts/*.cjs` | Yes |
| `sync-to-cache.cjs` | Deploy: rsync plugin/ to cache + marketplace, register in CC JSON files | Yes (idempotent) |
| `sync-marketplace.cjs` | Deploy: npm install in cache, write `.install-version` marker | Yes |

## Destructive Scripts (require confirmation)

| Script | Purpose |
|--------|---------|
| `wipe-chroma.cjs` | Delete all ChromaDB data (`~/.claude-mem/chroma/`) |
| `clear-failed-queue.cjs` | Delete failed messages from pending_messages across all DBs |
| `cleanup-duplicates.ts` | Remove duplicate observations by content_hash |

## Build Outputs (do not edit)

`*-hook.cjs`, `worker-service.cjs` — generated by `build-hooks.js` via esbuild. Read `src/hooks/*.ts` and `src/services/worker-service.ts` instead.
